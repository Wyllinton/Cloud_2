Módulo HTTPaaS deshabilitado

Inicie la consola en el host de VirtualBox con el módulo habilitado y los datos de su laboratorio:

./appgo -listen :8080 -httpaas \
  -httpaas-template template_server \
  -httpaas-network-mode hostonly -httpaas-network vboxnet0 \
  -httpaas-domain cloud.local -httpaas-dns-server 192.168.10.10 \
  -httpaas-dns-key /etc/bind/httpaas.key \
  -httpaas-guest-user np2deploy

La contraseña del invitado se puede pasar con NP2_HTTPAAS_PASSWORD para no dejarla en el historial del shell. Consulte docs/httpaas.md y los scripts de scripts/.

Antes de aprovisionar
  • La plantilla {{.HTTPaaSTemplate}} debe estar apagada; su disco multiconexión se usa como padre de un disco diferencial por instancia.
  • La red host-only (o el puente) debe permitir alcanzar la puerta de enlace y al servidor DNS.
  • El usuario invitado debe existir en la plantilla, tener contraseña, sudo sin contraseña y Guest Additions activas.
  • Bind9 debe aceptar actualizaciones con la llave TSIG configurada en -httpaas-dns-key, y el host debe tener nsupdate con la llave en modo 0600.
Seguridad

El zip se inspecciona en memoria antes de enviarse, el hostname se valida con RFC 1123 y la eliminación solo opera sobre máquinas del inventario creadas por este módulo. La plantilla y el servidor DNS están protegidos.

Flujo automatizado
  1. Aceptar → reserva: se valida el hostname y se elige la primera IPv4 libre del rango, sin reutilizar direcciones del inventario.
  2. Hardware: VBoxManage createmedium diff sobre el disco de la plantilla, createvm, modifyvm y storageattach.
  3. Invitado: tras arrancar en modo headless, se espera Guest Additions y se configuran hostname, IP estática, /etc/hosts y resolutor.
  4. Apache: se crea el directorio propio, el vhost, se valida con apache2ctl configtest y se recarga el servicio.
  5. Publicar → contenido: el zip se transfiere con copyto, se extrae en el document root y se ajusta el propietario a www-data.
  6. DNS: nsupdate elimina cualquier A anterior y agrega el nuevo registro en la zona local.
  7. Eliminación: apaga la VM, borra el A, ejecuta unregistervm --delete, elimina el disco diferencial y actualiza el inventario.
