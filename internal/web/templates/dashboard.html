Cómo funciona

  1. Ejecute la consola en el host con -mode guestcontrol (o -mode auto) para controlar la VM mediante VBoxManage y las Guest Additions, sin necesidad de SSH.
  2. Con el modo auto, la consola intenta SSH primero y cae automáticamente a Guest Additions si no hay conexión.
  3. En modo guestcontrol o auto, use Llave SSH de root para generar el par de llaves y descargar la llave privada.
  4. A partir de ese momento, SSH se convierte en el transporte principal; la consola sigue funcionando desde el navegador del host.
  5. Alternativamente, ejecute la consola en modo local dentro del invitado.
